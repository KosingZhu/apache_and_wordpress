# WooCommerce 导入工具集

本目录包含用于解决WooCommerce CSV导入问题的工具集合，以及相关的使用说明。

## 目录结构

```
woocommerce-tools/
├── README.md              # 本说明文档
├── import-test.php        # 导入环境测试脚本
└── woocommerce-import-check.php # 导入状态检查工具
```

## 工具文件说明

### 1. import-test.php

**功能说明**：简单的导入环境测试脚本，用于验证WooCommerce导入修复是否正确应用。

**主要功能**：
- 显示当前PHP配置信息（内存限制、最大执行时间、上传限制等）
- 检查修复插件是否正确加载
- 验证WooCommerce相关类是否存在
- 以HTML格式输出测试结果，直观显示系统状态

**使用方法**：直接在浏览器中访问该文件（例如：http://your-domain.com/woocommerce-tools/import-test.php）

### 2. woocommerce-import-check.php

**功能说明**：完整的WooCommerce导入状态检查工具，提供更详细的系统信息和建议。

**主要功能**：
- 显示系统设置（PHP版本、WordPress版本、WooCommerce版本）
- 检查PHP配置参数
- 验证导入修复插件是否激活
- 提供CSV导入建议和问题排查指南

**使用方法**：直接在浏览器中访问该文件（需要管理员权限）

## WooCommerce 导入修复插件

除了上述工具文件外，我们还开发了一个专用的WordPress插件来解决导入问题。

### 插件位置

插件位于WordPress插件目录：`wp-content/plugins/woocommerce-import-fix/`

### 插件主要功能

1. **增加导入超时限制**：将默认的20秒超时增加到300秒（5分钟）
2. **提升系统资源限制**：
   - 内存限制增加到512MB
   - 上传文件大小限制增加到64MB
   - POST最大大小增加到64MB
   - 最大执行时间增加到300秒
3. **优化批处理大小**：将导入批处理大小调整为20，提高导入效率
4. **确保导入器加载**：自动检测并确保WooCommerce CSV导入器正确加载
5. **导入进度监控**：添加JavaScript脚本来监控导入进度，防止进度条卡住

### 插件管理页面

插件在WooCommerce菜单下添加了"导入修复"子菜单，提供以下信息：
- 系统状态（PHP版本、WordPress版本、WooCommerce状态）
- 当前设置（导入超时、PHP执行时间、内存限制等）

### 插件激活方法

1. 登录WordPress管理后台
2. 进入"插件" > "已安装插件"
3. 找到"WooCommerce Import Fix"插件
4. 点击"激活"按钮

## 代码效果总结

本工具集和插件解决了WooCommerce CSV导入过程中常见的问题：

1. **解决导入卡住问题**：通过增加超时限制和添加进度监控，防止导入过程中因超时导致的卡住
2. **提高导入成功率**：增加系统资源限制，使大文件和复杂产品数据的导入更加稳定
3. **优化导入性能**：调整批处理大小，提高导入效率
4. **提供诊断工具**：帮助用户快速识别和解决导入环境问题

## 使用建议

1. 在进行大量产品导入前，建议先使用`import-test.php`测试环境
2. 对于大型CSV文件（超过1000行），建议拆分为多个较小的文件
3. 确保CSV文件格式正确，特别是列标题与WooCommerce要求匹配
4. 导入操作建议在网站流量较低的时段进行
5. 导入前建议备份数据库，以防发生意外
